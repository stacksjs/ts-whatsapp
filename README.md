# ts-whatsapp

A WhatsApp linked-device client in pure TypeScript: QR pairing, end-to-end encryption (Signal protocol), history sync, media and app state, with no native dependencies.

It links to your account as a companion device, the way WhatsApp Web does. WhatsApp does not offer a public API for personal accounts, so this is an unofficial client; using it is your decision.

See [docs/architecture.md](docs/architecture.md).
